# Abyss Tendril Boss — Minecraft 1.21.1 NeoForge

Boss entity with spawn egg, GeckoLib 4.9.3 model, and seven animations.
Requires **Minecraft 1.21.1**, **NeoForge 21.1.x**, **Java 21** and **GeckoLib 4.9.3**.

## Build
Open the **Actions** tab and run **Build Abyss Tendril Boss (NeoForge 1.21.1)**.
When the run succeeds, download the ZIP under *Artifacts*, extract the JAR and place it in your Minecraft `mods` folder alongside GeckoLib.

## In game
```mcfunction
/give @s abysstendril:abyss_tendril_spawn_egg
/summon abysstendril:abyss_tendril_beast
```
